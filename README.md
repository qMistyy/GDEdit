# gd-level-builder

A local TypeScript CLI that creates Geometry Dash SPWN source from a strictly validated BuildPlan. Gameplay and decoration are generated by deterministic TypeScript functions, not executable code returned by an AI. By default the CLI writes `output/build-plan.json` and `output/generated.spwn`.

## Setup

```sh
npm install
npm run build
```

## Generate

Run the built-in sample:

```sh
npm run generate
```

Generate a deterministic plan from a prompt, with no AI request:

```sh
npm run generate -- --prompt "dark industrial wave section"
```

Or load a version 1 BuildPlan JSON file:

```sh
npm run generate -- --plan build-plan.json
```

The strict schema supports cube and wave sections. Plan fields and section properties are validated; section start beats are limited to 0–1,000,000, durations to 5,000 beats, and group IDs to 1–999. Generated output is preflighted and capped at 5,000 objects, with object IDs and durations validated.

## Optional local Ollama

Only `--ollama` enables an HTTP request, and it targets `http://localhost:11434/api/generate`. It sends `stream: false` and a JSON output schema. Returned content is parsed and validated as BuildPlan data; only the TypeScript generator emits SPWN. On connection failure or timeout, the CLI warns and uses its deterministic local fallback.

```sh
npm run generate -- --prompt "dark industrial wave section" --ollama
npm run generate -- --prompt "neon wave" --ollama --model llama3.1
```

This tool writes local source and JSON only. It does not modify game memory, automate game input, bypass protections, or download assets.
